# Vlingual Cards

**Vlingual Channel**の英語学習語彙をスマホで復習できるPWAフラッシュカードアプリ

## 概要

Vlingual Cardsは、YouTubeチャンネル「Vlingual Channel」の英語学習コンテンツで学んだ語彙を効率的に復習するためのフラッシュカードアプリです。アカウント不要・無料・広告なしで、スマホ・タブレット・PCのブラウザから使えます。

### 主な機能

- ✅ **3階層ナビゲーション** - 事務所 → キャスト → 動画の順に選んで学習（YouTubeサムネイル表示、事務所の並び順カスタマイズ）
- ✅ **3Dフリップカード** - タップで表裏を切り替え
- ✅ **3段階評価** - 🔴覚えてない / 🟡だいたいOK / 🟢余裕
- ✅ **忘れかけた頃に戻ってくる復習** - 記録が進むのは1日1回。前に学んだ単語は忘れかけた頃に「今日の復習」に出てくる
- ✅ **今日の復習** - ホーム画面に全動画横断の復習導線を表示（復習がある日のみ）
- ✅ **進捗の自動保存** - ブラウザ（localStorage）に保存。リロード/アプリ切替でも同日ならセッションの続きから再開
- ✅ **語彙一覧 + 「覚えた」チェック** - チェックした単語は出題停止。「余裕」を積み上げた単語は自動でチェックが付く
- ✅ **学習データの引っ越し** - 進捗のエクスポート/インポート（JSONコピペ）で端末間移行・バックアップ
- ✅ **音声読み上げ** - 英単語の発音を確認（Web Speech API）。カード裏面の🔊でいつでも聞き直せる
- ✅ **テーマ切り替え** - ダーク/ライト（初回はOS設定に追従）
- ✅ **ディープリンク** - `?video=<動画ID>` で動画の学習画面に直行（概要欄・固定コメントに貼れる）
- ✅ **PWA対応** - ホーム画面に追加してアプリのように利用可能
- ✅ **レスポンシブデザイン** - スマホ・タブレット・PC対応
- ✅ **Vercel Analytics** - Cookieレスのアクセス解析

**注意**: Service Workerは未実装のため、**オフラインでは利用できません**（Phase 2で対応予定）。

- **フレームワーク**: React 18 + TypeScript

## ローカル開発

### 前提条件

- Node.js 18以上
- npm 9以上

### セットアップ

```bash
# リポジトリをクローン
git clone https://github.com/w-udagawa/vlingual-cards.git
cd vlingual-cards

# 依存関係をインストール
npm install

# 開発サーバーを起動（http://localhost:5173/）
npm run dev
```

### コマンド一覧

```bash
npm run dev           # 開発サーバー起動
npm run build         # 本番用ビルド（TypeScriptコンパイル + Viteビルド）
npm run preview       # ビルド結果をプレビュー
npm run lint          # ESLint実行
npm test              # ユニットテスト実行（Vitest、62テスト）
npm run validate-csv  # CSV品質チェック（public/vocab.csv を検証）
```

GitHub Actionsでもpush時に `validate-csv` が実行され、問題があれば**非ブロッキングの警告**として表示されます（ビルドは止めません）。

## CSVデータ形式

語彙データは `public/vocab.csv` で管理します。パーサはRFC 4180準拠・**ヘッダー名ベース**で、列の追加にも耐えます。

### 9列形式（推奨）

```csv
単語,和訳,難易度,品詞,文脈,動画URL,動画タイトル,事務所,キャスト名
accomplish,達成する,中級,動詞,"I want to accomplish my goals this year. (今年は目標を達成したい)",https://youtu.be/abc123,英語学習動画,事務所名,キャスト名
```

### 列の説明

| 列名 | 説明 | 必須 | 例 |
|------|------|------|-----|
| 単語 | 英単語 | ✅ | accomplish |
| 和訳 | 日本語訳 | ✅ | 達成する |
| 難易度 | 初級/中級/上級 | ✅ | 中級 |
| 品詞 | 動詞/名詞/形容詞/スラング など | ✅ | 動詞 |
| 文脈 | 例文（英語＋日本語） | ✅ | I want to accomplish my goals this year. (今年は目標を達成したい) |
| 動画URL | 関連動画へのリンク | ✅ | https://youtu.be/abc123 |
| 動画タイトル | 動画のタイトル | ⭕ | 英語学習動画 |
| 事務所 | キャストの所属事務所 | ⭕ | ホロライブ |
| キャスト名 | キャストの名前 | ⭕ | 古石ビジュー |

### 必須ルール・パーサの挙動

- **後方互換**: 6列/7列形式も読み込めます。未知の追加列があっても壊れません
- **難易度**: 必ず `初級` / `中級` / `上級` のいずれか
- **文脈にカンマや改行がある場合**はダブルクォートで囲む（エスケープされたクォート `""` にも対応）
- **品詞「スラング」**を正式サポート
- **同一動画のタイトルは全行同じにする**（揺れた場合は初出行のタイトルが採用され、`validate-csv` が警告を出します）
- **同一動画内の重複行**は自動的に1枚に統合されます
- **不正な行は無言でスキップしません**: アプリのUIバナーに件数が表示され、詳細はブラウザのコンソールで確認できます

### CSV更新ワークフロー

**重要**: アプリは Vercel 上の `/vocab.csv` を読み込みます。CSVの反映には **GitHubへのpush → Vercelの自動ビルド・デプロイ（1〜2分）** が必要です（即時反映ではありません）。

#### オンライン編集

1. GitHubリポジトリ: https://github.com/w-udagawa/vlingual-cards
2. `public/vocab.csv` をクリック
3. 鉛筆アイコン（Edit）をクリックしてデータを編集
4. "Commit changes" をクリック
5. **Vercel が自動的にビルド・デプロイ**（1〜2分で反映）

#### ローカル編集

1. `public/vocab.csv` を編集
2. `npm run validate-csv` で品質チェック（推奨）
3. `git add public/vocab.csv && git commit -m "Update vocabulary"`
4. `git push origin main`
5. **Vercel が自動的にビルド・デプロイ**（1〜2分で反映）

## 学習モデル（v3.0.0）

ユーザーから見える仕組みはシンプルです：

- 🔴 **覚えてない**: すぐまた出てきます
- 🟡 **だいたいOK**: しばらくしてまた出てきます
- 🟢 **余裕**: 当分出てきません
- **記録が進むのは1日1回**。同じ日に何度評価しても、翌日以降の出方は変わりません
- 前に学んだ単語は、**忘れかけた頃に「今日の復習」に出てきます**

### 学習の流れ

- **1回の学習セットは最大20枚**。単語が多い動画は自動的に複数セットに分かれます（完了画面の「次のセットへ」で続行）
- セット内の再出題: 覚えてない→3枚後 / だいたいOK→8枚後 / 余裕→そのセットでは出ない
- **今日の復習**: ホーム画面に「🔁 今日の復習（N枚）」を表示。全動画横断・復習期日が来たカードのみ・新規は混ぜない・上限30枚（超過分は翌日に持ち越し）
- **セッション復帰**: リロードやアプリ切替をしても、同じ日・同じスコープなら続きから再開
- **完了画面**: 🎉 +「明日はN枚が復習に来ます」+「▶ この動画をもう一度見る」

内部のスケジューリング仕様（開発者向け）は **[docs/learning-model.md](docs/learning-model.md)** が唯一の正典です。

## 進捗データ

- 学習進捗はブラウザの localStorage（キー: `vlc_learning_v1`）に自動保存されます。スキーマの詳細は [docs/learning-model.md](docs/learning-model.md) を参照
- 音声設定・テーマ・事務所の並び順もlocalStorageに保存されます
- **エクスポート/インポート**: アプリ内ヘルプモーダルの「学習データの引っ越し」からJSONテキストをコピペで書き出し・取り込みできます（端末間移行・バックアップ用）
- 語彙一覧の「覚えた」チェックは学習進捗と完全統合されています（チェック=出題停止、外すと再出題）

## 画面構成

1. **ホーム（キャスト一覧）**: 事務所ごとのセクションにキャストを表示。⚙️ボタンで事務所の並び順を変更可能。復習がある日は「🔁 今日の復習」ボタンを表示
2. **動画一覧**: 選んだキャストの動画をサムネイル付きで表示（語彙数・定着数・📋語彙一覧ボタン）。「全ての動画」でまとめて学習も可能
3. **学習画面**: フラッシュカード + 3段階評価。ヘッダーに残り枚数と📋語彙一覧ボタン。戻るボタンは常に表示

## 音声読み上げ

- **対応ブラウザ**: Chrome、Safari、Edge（Web Speech API対応ブラウザ）
- **言語**: 英語（en-US）、速度0.9倍
- **トグル**: ヘッダーのスピーカーアイコンで切り替え（デフォルト: OFF）
- **リプレイ**: カード裏面の🔊ボタンで、音声設定がOFFでも単発再生可能

## トラブルシューティング

### CSVが読み込めない

- ネットワーク接続を確認してください
- エラー画面の「再試行」ボタンで再読み込みできます
- 読み込み失敗時はサンプルデータで動作します（画面上部に警告バナーが表示されます）

### 語彙データに問題がある

- 画面上部に「⚠️ 語彙データにN件の問題があります」バナーが出た場合、詳細はブラウザのDevToolsコンソールで確認できます
- `npm run validate-csv` でローカルでもチェックできます

### 音声が再生されない

- ブラウザがWeb Speech APIに対応しているか確認してください
- ヘッダーのスピーカーアイコンがONになっているか確認してください（カード裏面の🔊は設定OFFでも再生できます）

### 進捗が保存されない

- ブラウザのlocalStorageが有効になっているか確認してください
- プライベートブラウジングモード（シークレットモード）では、ブラウザを閉じると消えます
- ホーム画面に追加（PWAインストール）して使うと進捗が消えにくくなります
- バックアップにはヘルプモーダルの「学習データの引っ越し」（エクスポート）が使えます

### デプロイ後に変更が反映されない

- ハードリロード: Ctrl+Shift+R (Windows) / Cmd+Shift+R (Mac)
- シークレットウィンドウで開いて確認
