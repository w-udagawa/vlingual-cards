# 学習モデル仕様書（正典）

**Version**: 3.0.0
**この文書が学習モデル・カードID・ストレージの唯一の正典。** コード・ヘルプ・他ドキュメントがこの文書と食い違う場合、この文書に合わせて直すこと。

実装: [src/lib/schedule.ts](../src/lib/schedule.ts) / [src/lib/session.ts](../src/lib/session.ts) / [src/lib/store.ts](../src/lib/store.ts) / [src/lib/ids.ts](../src/lib/ids.ts)
テスト: `src/lib/__tests__/`（`npm test`）

## 設計原則

1. **「1動画をやり切る」体験を保つ**。間隔反復は裏側の帳簿であり、UIにSRS用語（箱・間隔・忘却曲線）は出さない。
2. **ヘルプ3行で説明できない仕組みは入れない**。ユーザー向け説明は「🔴すぐまた出る / 🟡しばらくしてまた出る / 🟢当分出ない」+「記録が進むのは1日1回」。
3. **CSVは読み取り専用の教材、localStorageは学習帳簿**。CSVにID列・進捗列は追加しない。

## カードID

```
id = videoId + "::" + normalize(単語)
normalize = NFC正規化 + trim + 連続空白を1つに圧縮
```

- 定義は [src/lib/ids.ts](../src/lib/ids.ts) の1箇所のみ。他で再実装しない。
- 大文字小文字は**保持**する（`praise`（動詞）と `Praise`（名詞）は別カード）。
- 同一単語でも動画が違えば**別カード**（文脈=実発話が違うため）。
- 同一動画内に同じ単語が複数行ある場合、パース時に**初出行へマージ**する。
- トレードオフ（受容済み）: CSV上で単語のタイポを直すと、そのカードの進捗は1枚分消える。

## 日付の定義

「1日」は**端末のローカルタイムゾーンの暦日**。`todayLocal()` = ローカル暦日のepoch日数。
UTC日は使わない（JSTでは朝9時に日付が変わってしまうため）。時刻は持たない（日付粒度で十分）。

## カードの状態機械

| 状態 | 意味 | UI表示 |
|---|---|---|
| `new` | 未評価（レコードなし、または手動チェック解除のtombstone） | 未学習 |
| `learning` | 復習サイクル中。箱1〜5と`due`（次回復習日）を持つ | 学習中 |
| `mastered` | 箱5を「余裕」で通過、または一覧で手動チェック | 覚えた ✓ |

```
new ──(初回評価)──▶ learning(箱1〜2) ──(余裕で箱+1…箱5通過)──▶ mastered
                        ▲    │
                        └────┘ 覚えてない→箱1へ降格 / だいたいOK→同じ箱で間隔リピート
mastered ──(一覧でチェック解除)──▶ new（tombstone）
mastered ──(覚えてない)──▶ learning(箱1)
```

## Leitner 5箱と間隔

| 箱 | 次回まで |
|---|---|
| 1 | 1日 |
| 2 | 3日 |
| 3 | 7日 |
| 4 | 14日 |
| 5 | 30日 |

- `due = today + interval[box]`（評価時に設定）。
- **期日超過は無罰**: `due <= today` なら出題対象になるだけ。超過日数による降格はない（不定期利用ユーザーを罰しない）。

## 評価の遷移表（applyRating）

| 評価 | new | learning | mastered |
|---|---|---|---|
| 🔴 覚えてない | 箱1へ（lapses=0） | **箱1へ降格（同日でも即時）**。lapsesは日単位で+1 | 箱1へ（忘れた申告） |
| 🟡 だいたいOK | 箱1へ | **同じ箱**のまま間隔リピート（昇格しない） | 変化なし |
| 🟢 余裕 | **箱2へ**スキップ | 箱+1。箱5なら → mastered | 変化なし |

**同日ルール**: 箱・dueが動くのは1日1回（`lastRatedDay`で判定）。同日2回目以降のOK/余裕は**無変化**（セッション内の再出題制御にのみ使われる）。降格（覚えてない）だけは同日でも即時反映。これがないと1セッション連打で箱5まで昇格でき、間隔反復が形骸化する。

`lapses` は「覚えてないを押した**日数**」（同日連打では増えない）。苦手検出（Phase 2）用。

## セッション（セット）構成

- **1セット = 最大20枚**（1動画の中央値が20語。普通の動画は従来通り1セットでやり切れる）。
- 構成: スコープ内の**due到来復習カード（古い順）を優先** → 残り枠を**未学習カード（CSV順）**で充填 → 全体をシャッフル。
- masteredカードは出題されない。
- セット番号（パート3/16等）はUIに見せない。常に「今日のぶん」として出す。
- 新規:復習の固定比率は設けない（復習優先充填により自然に決まる）。

### 今日の復習

- ホーム（キャスト一覧）に「🔁 今日の復習（N枚）」。N=0なら非表示。
- **全動画横断・due到来のみ・新規は混ぜない・上限30枚**・古い順。超過分は翌日に無罰で繰り越し。

### 出題キュー（再挿入付き決定的キュー）

乱数抽選は廃止。セットのキューを先頭から出題し、評価後:

- 🔴 覚えてない → **3枚後**に再挿入
- 🟡 だいたいOK → **8枚後**に再挿入
- 🟢 余裕 → 再挿入しない（セットから卒業）

残りが1枚以上あるとき、直前のカードが即座に再出題されることはない。キューが空になったら完了画面（「明日はN枚が復習に来ます」+「▶ この動画をもう一度見る」）。

### セッション永続化

評価のたびにキューをストアへ書き戻す。**同じ日・同じスコープ**で再入場するとキューが復帰する（リロード/タスクキル対応）。日が変わっていたらセットを組み直す。

## 「覚えた」チェックボックス

語彙一覧のチェック = **masteredの手動スイッチ**。

- ON → mastered（恒久的に出題停止。30日後に再出題されたりは**しない**）
- OFF → new に戻す（レコードは`state:'new'`のtombstoneとして残す。削除するとタブ間マージでmasteredが復活するため）
- 学習で箱5を通過したカードは自動的にチェック済みとして表示される

## ストレージ（localStorage）

キー: `vlc_learning_v1`

```jsonc
{
  "version": 1,
  "migratedLegacy": true,
  "cards": {
    "<cardId>": { "state": "learning", "box": 3, "due": 20701, "lastRatedDay": 20694, "lapses": 1 }
  },
  "session": {  // null = アクティブセッションなし
    "scopeId": "video:cG1mzF2rc4M",  // "video:<id>" | "cast:<名前>" | "all" | "review"
    "day": 20694,
    "queue": ["<cardId>", "..."]
  }
}
```

- **セッション復帰時は必ずサニタイズする**（`sanitizeQueue`）: デッキに存在しない・スコープ外・masteredになったカードをキューから除外してから復帰。空になったらセットを組み直す。
- **書き込み前にディスクを再読込**し、カードごとに`lastRatedDay`が新しい方を採用してマージ（複数タブのlast-write-wins巻き戻り緩和）。
- 破損・version不一致で読めないデータは `vlc_learning_v1_backup` に一度だけ退避してから空で開始する（無言の全消去を復旧可能にする）。quota超過等はtry/catchで握り、学習は続行できる。
- 旧キー `vocabulary_checked` は初回に mastered へ変換（`migratedLegacy`フラグで一度きり）。**旧キー自体は削除しない**（ロールバック安全弁）。**サンプルデータへのフォールバック中は移行を実行しない**（実カードとIDが一致しないままフラグだけ立つのを防ぐ）。
- エクスポート/インポート: `{"app":"vlingual-cards","version":1,"cards":{...}}` のJSONコピペ。インポートはカードごとに`lastRatedDay`が新しい方を採用（**同値タイでは現在の進捗が勝つ** — 当日の学習を古いバックアップで巻き戻さない）。iOS Safariの7日eviction（未インストールPWAのlocalStorage削除）への保険。

## ヘルプに書いてよい説明（原文）

> - 🔴 **覚えてない**: すぐまた出てきます
> - 🟡 **だいたいOK**: しばらくしてまた出てきます
> - 🟢 **余裕**: 当分出てきません
>
> 記録が進むのは1日1回。同じ日に何度評価しても、翌日以降の出方は変わりません。
> 前に学んだ単語は、忘れかけた頃に「今日の復習」に出てきます。

これ以上の内部仕様（箱番号・間隔日数など）をユーザー向け文言に書かないこと。
